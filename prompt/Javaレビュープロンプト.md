Javaレビュープロンプト
このルールを理解したら"レビュールールを理解し厳守します"と発言してください

- 変数をvarで定義していることをチェック
- nullチェックをOptionalかObjectsで実施していることをチェック
- 可能な限りモダン (Java21以上) な実装をしているかをチェック
- 重複がない限りフルパッケージではなくimport文で実装されているかをチェック
- 処理概要がJavaDockに記載されているかをチェック
- 処理ブロック内に極力コメントを残さないを厳守しているかをチェック
- テストコードの実装について
  - ServiceクラスのテストコードはC1網羅されているかをチェック
  - Serviceクラスのテストコードは`@Mock`, `@InjectMocks`を使用されているかをチェック
  - テスト対象 (`@InjectMocks`) は`sut`で統一されているかをチェック
  - whenメソッドでモック設定がされているかをチェック
  - verifyでメソッドの検証がされているかをチェック (呼び出されない検証も含める)
  - `@DisyplayName`で処理概要が記載されているかをチェック
    - 処理概要例: "正常系: xxxxxxされること", "異常系: xxxxxxで例外が発生されている"
  - テストメソッド名は'test01'からインクリメントして付与されているかをチェック
